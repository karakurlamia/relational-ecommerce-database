# Relational E-Commerce Database
This repository contains a cleaned and structured relational e-commerce database designed for SQL analysis, data modeling practice, and analytical querying.
## Dataset Overview
The dataset represents a simplified e-commerce system with customers, orders, products, branches, and order details.  
It is suitable for practicing joins, aggregations, business-focused SQL analysis, and data validation.
## Tables
- *customers*: Customer demographic and registration information  
- *branches*: Store/branch information  
- *orders*: Order-level data including dates and total amounts  
- *order_details*: Line-item level order details (products, quantities, prices)  
- *products*: Product catalog and pricing information  
All tables follow a relational structure using primary and foreign keys.
